# External Dependencies

This document lists all external dependencies, their licenses, versions, and usage in the project.

## gem5 Simulator

- **Repository**: https://github.com/gem5/gem5
- **License**: BSD 3-Clause License
- **Usage**: Full-system simulation of RISC-V 32-bit architecture
- **Location**: `src/gem5/` (Git submodule)
- **Pinned Version**: v25.0.0.1 (hotfix release, pinned 2025-11-23)
- **Build System**: SCons
- **Dependencies**:
  - Python 3.11+
  - protobuf
  - libgoogle-perftools-dev
  - libboost-all-dev
  - scons

**Installation Notes**:
```bash
# gem5 is added as a Git submodule
git submodule add https://github.com/gem5/gem5.git src/gem5
cd src/gem5
git checkout <stable-tag>  # v23.1 or latest stable
```

## Zephyr RTOS

- **Repository**: https://github.com/zephyrproject-rtos/zephyr
- **License**: Apache License 2.0
- **Usage**: Real-time operating system for automotive workload execution
- **Location**: `src/zephyr/` (west workspace)
- **Pinned Version**: To be determined (will be documented after west init)
- **Build System**: west + cmake
- **Dependencies**:
  - west tool (`pip3 install west`)
  - Zephyr SDK
  - device-tree-compiler (dtc)
  - ninja-build

**Installation Notes**:
```bash
# Zephyr uses west tool for workspace management
pip3 install west
west init src/zephyr
cd src/zephyr
west update
```

**Zephyr SDK**:
- Download from: https://github.com/zephyrproject-rtos/sdk-ng/releases
- Recommended version: Latest stable (0.16.x or newer)
- Installation path: `~/zephyr-sdk` (user-local)

## RISC-V GNU Toolchain

- **Repository**: https://github.com/riscv-collab/riscv-gnu-toolchain
- **License**: GPL v2+ (GCC), GPL v3+ (binutils), LGPL v2.1+ (glibc/newlib)
- **Usage**: Cross-compilation for RISC-V 32-bit targets
- **Required**: `riscv32-unknown-elf-gcc` (bare-metal toolchain)
- **Version**: Any recent stable version supporting RV32IMAC
- **Installation**: System-level (via package manager or manual build)

**Ubuntu Installation**:
```bash
# Option 1: Pre-built packages (if available)
sudo apt install gcc-riscv64-unknown-elf

# Option 2: Manual build
git clone https://github.com/riscv-collab/riscv-gnu-toolchain.git
cd riscv-gnu-toolchain
./configure --prefix=/opt/riscv --with-arch=rv32imac --with-abi=ilp32
make
```
